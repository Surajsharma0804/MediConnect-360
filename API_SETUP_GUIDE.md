# 🔑 Complete API Setup Guide

## Required API Keys and Services

### 1. Google OAuth Setup

**Purpose**: User authentication with Google accounts

**Steps**:
1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Create a new project or select existing one
3. Enable Google+ API and Google OAuth2 API
4. Go to "Credentials" → "Create Credentials" → "OAuth 2.0 Client IDs"
5. Configure OAuth consent screen:
   - Application name: "MediConnect 360"
   - Authorized domains: Add your domain
6. Create OAuth 2.0 Client ID:
   - Application type: Web application
   - Authorized JavaScript origins:
     - `http://localhost:3000` (development)
     - `https://medi-connect-360.vercel.app` (production)
   - Authorized redirect URIs:
     - `http://localhost:5000/auth/google/callback` (development)
     - `https://mediconnect-backend.onrender.com/auth/google/callback` (production)

**Environment Variables**:
```bash
# Frontend (Vercel)
VITE_GOOGLE_CLIENT_ID=your-google-client-id

# Backend (Render)
GOOGLE_CLIENT_ID=your-google-client-id
GOOGLE_CLIENT_SECRET=your-google-client-secret
```

### 2. Gemini AI Setup (FREE)

**Purpose**: AI-powered medical assistance and diagnostics

**Steps**:
1. Go to [Google AI Studio](https://aistudio.google.com/app/apikey)
2. Sign in with your Google account
3. Click "Create API Key"
4. Copy the generated API key

**Limits**: 60 requests per minute (free tier)

**Environment Variables**:
```bash
# Backend (Render)
GEMINI_API_KEY=your-gemini-api-key
```

### 3. Resend Email Setup (FREE)

**Purpose**: Transactional emails (verification, notifications, etc.)

**Steps**:
1. Go to [Resend](https://resend.com/)
2. Sign up for a free account
3. Go to API Keys section
4. Create a new API key
5. Verify your domain (optional for testing)

**Limits**: 3,000 emails per month (free tier)

**Environment Variables**:
```bash
# Backend (Render)
RESEND_API_KEY=re_your-resend-api-key
FROM_EMAIL=noreply@yourdomain.com
FROM_NAME=MediConnect 360
```

### 4. Stripe Payment Setup

**Purpose**: Payment processing for premium features

**Steps**:
1. Go to [Stripe Dashboard](https://dashboard.stripe.com/)
2. Create account or sign in
3. Go to Developers → API Keys
4. Copy both Publishable key and Secret key
5. For testing, use test keys (they start with `pk_test_` and `sk_test_`)

**Environment Variables**:
```bash
# Frontend (Vercel)
VITE_STRIPE_PUBLISHABLE_KEY=pk_test_your-publishable-key

# Backend (Render)
STRIPE_SECRET_KEY=sk_test_your-secret-key
```

### 5. Database Setup (Render)

**Purpose**: PostgreSQL database and Redis cache

**Steps**:
1. Database is automatically created by `render.yaml`
2. Connection strings are auto-generated
3. No manual setup required

**Environment Variables** (Auto-generated by Render):
```bash
DATABASE_URL=postgresql://user:pass@host:5432/mediconnect
REDIS_URL=redis://user:pass@host:6379
```

## 🚀 Deployment Steps

### Step 1: Set Up API Keys

1. **Get all API keys** from the services above
2. **Store them securely** - never commit to Git

### Step 2: Deploy Backend (Render)

1. Go to [Render Dashboard](https://dashboard.render.com/)
2. Click "New +" → "Blueprint"
3. Connect your GitHub repository
4. Select `MediConnect-360` repository
5. Render will detect `render.yaml` and create:
   - PostgreSQL database
   - Redis cache
   - Backend web service
6. **Add environment variables** in Render dashboard:
   ```bash
   GEMINI_API_KEY=your-gemini-api-key
   RESEND_API_KEY=re_your-resend-api-key
   GOOGLE_CLIENT_ID=your-google-client-id
   GOOGLE_CLIENT_SECRET=your-google-client-secret
   STRIPE_SECRET_KEY=sk_test_your-stripe-secret
   ```

### Step 3: Deploy Frontend (Vercel)

1. Go to [Vercel Dashboard](https://vercel.com/)
2. Click "Add New..." → "Project"
3. Import from GitHub: `MediConnect-360`
4. **Add environment variables** in Vercel dashboard:
   ```bash
   VITE_API_URL=https://mediconnect-backend-xxxx.onrender.com
   VITE_WS_URL=wss://mediconnect-backend-xxxx.onrender.com
   VITE_ENV=production
   VITE_GOOGLE_CLIENT_ID=your-google-client-id
   VITE_STRIPE_PUBLISHABLE_KEY=pk_test_your-publishable-key
   ```
5. Deploy

### Step 4: Configure GitHub Secrets

For CI/CD pipeline, add these secrets in GitHub repository settings:

```bash
# Vercel
VERCEL_TOKEN=your-vercel-token
VERCEL_ORG_ID=your-vercel-org-id
VERCEL_PROJECT_ID=your-vercel-project-id

# Render
RENDER_API_KEY=your-render-api-key
RENDER_SERVICE_ID=your-render-service-id

# API Keys (for build-time)
VITE_API_URL=https://mediconnect-backend-xxxx.onrender.com
VITE_GOOGLE_CLIENT_ID=your-google-client-id
VITE_STRIPE_PUBLISHABLE_KEY=pk_test_your-publishable-key
```

## 🔒 Security Best Practices

### Environment Variables
- ✅ Never commit API keys to Git
- ✅ Use different keys for development/production
- ✅ Rotate keys regularly
- ✅ Use strong, random secrets for JWT

### OAuth Configuration
- ✅ Restrict authorized domains
- ✅ Use HTTPS in production
- ✅ Validate redirect URIs
- ✅ Enable OAuth consent screen

### Database Security
- ✅ Use strong passwords
- ✅ Enable SSL connections
- ✅ Regular backups
- ✅ Monitor access logs

## 🆘 Troubleshooting

### Common Issues

**OAuth Error: "redirect_uri_mismatch"**
- Check authorized redirect URIs in Google Console
- Ensure URLs match exactly (including http/https)

**Gemini API Error: "API key not valid"**
- Verify API key is correct
- Check if API is enabled in Google Cloud Console

**Email Error: "Domain not verified"**
- Verify your domain in Resend dashboard
- Use `noreply@resend.dev` for testing

**Database Connection Error**
- Check if Render services are running
- Verify DATABASE_URL format
- Check firewall settings

### Getting Help

1. **Check service logs** in Render/Vercel dashboards
2. **Monitor API quotas** in respective service dashboards
3. **Test endpoints** individually to isolate issues
4. **Check environment variables** are set correctly
