# MediConnect 360

A comprehensive healthcare platform connecting patients with medical professionals through secure, AI-powered digital health solutions.

## 🌟 Features

- 🔐 **Secure OAuth Authentication** - Google OAuth integration
- 🏥 **Medical Document Management** - Secure storage and sharing
- 🤖 **AI-Powered Symptom Checker** - Advanced symptom analysis
- 📱 **Progressive Web App** - Offline capability and push notifications
- 🔒 **Enterprise Security** - HIPAA compliant with end-to-end encryption

## 🚀 Quick Start

```bash
# Clone and install
git clone https://github.com/Surajsharma0804/MediConnect-360.git
cd MediConnect-360
npm install && cd backend && npm install && cd ..

# Start services
docker-compose up -d
npm run dev
cd backend && npm run start:dev
```

## 🏗️ Tech Stack

- **Frontend**: React 18 + TypeScript + Vite
- **Backend**: NestJS + TypeORM + PostgreSQL  
- **Authentication**: JWT + OAuth (Google)
- **Deployment**: Vercel + Render
