## 🚀 Quick Start

### Prerequisites

- **Node.js** 18+ ([Download](https://nodejs.org/))
- **Docker Desktop** ([Download](https://www.docker.com/products/docker-desktop))
- **Git** ([Download](https://git-scm.com/))

### Automated Setup (Recommended)

**Windows:**
```bash
cd scripts
setup.bat
```

**macOS/Linux:**
```bash
chmod +x scripts/setup.sh
./scripts/setup.sh
```

### Manual Setup

#### 1. Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/MediConnect-360.git
cd MediConnect-360
```

#### 2. Start Docker Services

```bash
docker-compose up -d
```

**Services Started:**
- PostgreSQL (port 5432)
- Redis (port 6379)
- MinIO S3 (port 9000, 9001)

#### 3. Setup Backend

```bash
cd backend
npm install
cp .env.example .env
# Edit .env with your API keys (see below)
npm run start:dev
```

**Backend:** http://localhost:5000

#### 4. Setup Frontend

```bash
# In project root
npm install
cp .env.example .env
# Edit .env with your configuration
npm run dev
```

**Frontend:** http://localhost:5173

## 🔑 Required API Keys

### 1. Google Gemini AI (REQUIRED)
**Purpose:** AI symptom checker, health assistant

1. Visit: https://aistudio.google.com/app/apikey
2. Click "Create API Key"
3. Copy key to `backend/.env`:
   ```
   GEMINI_API_KEY=your-key-here
   ```

### 2. Resend Email (REQUIRED)
**Purpose:** Email notifications, password reset

1. Visit: https://resend.com/signup
2. Get API key from dashboard
3. Add to `backend/.env`:
   ```
   RESEND_API_KEY=your-key-here
   FROM_EMAIL=onboarding@resend.dev
   ```

### 3. Google OAuth (Optional)
**Purpose:** Sign in with Google

1. Visit: https://console.cloud.google.com/apis/credentials
2. Create OAuth 2.0 Client ID
3. Add to `backend/.env`:
   ```
   GOOGLE_CLIENT_ID=your-client-id
   GOOGLE_CLIENT_SECRET=your-client-secret
   ```

### 4. GitHub OAuth (Optional)
**Purpose:** Sign in with GitHub

1. Visit: https://github.com/settings/developers
2. Create OAuth App
3. Add to `backend/.env`:
   ```
   GITHUB_CLIENT_ID=your-client-id
   GITHUB_CLIENT_SECRET=your-client-secret
   ```

### 5. Stripe (Optional)
**Purpose:** Payment processing

1. Visit: https://dashboard.stripe.com/test/apikeys
2. Get test keys
3. Add to `backend/.env`:
   ```
   STRIPE_SECRET_KEY=sk_test_...
   STRIPE_WEBHOOK_SECRET=whsec_...
   ```

**See [docs/GET_API_KEYS.md](docs/GET_API_KEYS.md) for detailed instructions.**
