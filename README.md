## 🚀 **Quick Start**

### **Prerequisites**
- Node.js 18+
- Docker & Docker Compose
- Git

### **1. Clone Repository**
```bash
git clone https://github.com/yourusername/mediconnect-360.git
cd mediconnect-360
```

### **2. Environment Setup**
```bash
# Copy environment files
cp .env.example .env
cp .env.example backend/.env

# Edit .env files and add your API keys:
# - GEMINI_API_KEY (FREE: https://aistudio.google.com/app/apikey)
# - RESEND_API_KEY (FREE: https://resend.com/api-keys)
# - STRIPE keys (Test mode: https://dashboard.stripe.com/test/apikeys)
```

### **3. Start Services**
```bash
# Start PostgreSQL, Redis, MinIO
docker-compose up -d

# Install dependencies
npm install
cd backend && npm install && cd ..

# Start backend
cd backend && npm run start:dev

# Start frontend (in new terminal)
npm run dev
```

### **4. Access Application**
- **Frontend:** http://localhost:5173
- **Backend:** http://localhost:5000
- **API Docs:** http://localhost:5000/api
- **MinIO Console:** http://localhost:9001 (minioadmin/minioadmin)
